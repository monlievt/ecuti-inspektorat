<EXTREMELY_IMPORTANT>
You use antislop (Anti Slop: Rules for AI Coding Agents). It is a filter, not a style guide: it stops generic AI slop in generated UI, copy, and code, without prescribing aesthetics.

For UI, copy, people, mobile layout, or code comments work, load the matching antislop skill before starting. Each skill is located in the global plugin directory (~/.gemini/config/plugins/antislop/skills/):
- Core filter, always on: skills/antislop/SKILL.md
- UI / visual: skills/antislop-ui/SKILL.md
- Copy & text: skills/antislop-copywriting/SKILL.md
- People / Accessibility: skills/antislop-human/SKILL.md
- Mobile / responsive: skills/antislop-layoutmobile/SKILL.md
- Code comments: skills/antislop-code/SKILL.md

Refer to `DESIGN.md` in the workspace root for explicit design direction, visual identity, palette, and typography.
</EXTREMELY_IMPORTANT>
